Connecting to Your
Pico W Hotspot

Your Pico W creates its own WiFi network. No school network needed. Follow these steps every time you want to view the dashboard.

📡 No school WiFi needed Always: 192.168.4.1 Works on phone or laptop 5 steps · 2 minutes

Steps to connect

  • 1
    Run the code in Thonny

    Open Thonny, make sure your Pico W is plugged in via USB, and press the green ▶ Run button. Watch the Shell panel at the bottom.

    ✅ What you should see in the Shell

    After a few seconds these lines appear — this means the hotspot is ready:

    Thonny Shell
    Starting Access Point...
Access Point ready!
Network name: YarningMonitor
Password:     pico1234
Web server running at http:// 192.168.4.1
    ⚠️ Nothing appearing in the Shell?

    Check the bottom-right corner of Thonny — it must say MicroPython (Raspberry Pi Pico). If it says something else, click it and select the Pico W from the list.

  • 2
    Go to WiFi settings on your device

    On the device you want to view the dashboard on — your phone, laptop, or tablet — open the WiFi settings. Do not close Thonny or unplug the Pico W.

    💡 Internet will stop working while connected

    This is completely normal. Your device is connected to the Pico W's private network, not the internet. To use the internet again during the lesson, switch back to the school WiFi when you are done viewing the dashboard.

  • 4
    Open a browser and go to the address

    Once connected to YarningMonitor, open any browser (Safari, Chrome, Edge — any of them work). Type this address in the address bar and press Enter/Go:

    Type this in your browser
    192.168.4.1
    ⚠️ Important — type it exactly like this
    • Type 192.168.4.1 — not google.com, not anything else
    • Do not add www. before it
    • You do not need to type http:// — the browser adds it automatically
    • If it says "site can't be reached" — wait 10 seconds and try again. The Pico W may still be starting up.
  • ✓

Something not working?

ProblemFix
YarningMonitor doesn't appear in WiFi list Check the Thonny Shell — it must say "Access Point ready!". If not, press Run again. Also try scrolling down in the WiFi list or tapping "Refresh".
Password not accepted Type exactly pico1234 — all lowercase, no spaces. If your version of the code uses a different password, check the AP_PASSWORD line in Thonny.
Connected to WiFi but browser says "can't reach site" Make sure you typed 192.168.4.1 exactly. Wait 10–15 seconds after connecting to WiFi before trying the browser — the Pico W needs a moment. Try a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
Page loads but shows dashes instead of numbers The DHT22 sensor gave an error reading. Wait 5 seconds — the page refreshes automatically and the reading should appear. If it keeps showing dashes, check the sensor is firmly pushed into GP13 on the breadboard.
LED button does nothing Check the physical wiring — long leg of LED through a 220Ω resistor to GP11, short leg to GND. Also check the code is still running in Thonny (Shell should not show an error).
Page stopped updating The Pico W may have hit an error. Check the Thonny Shell for a red error message. Press Stop then Run again to restart.
How do I get internet back on my phone? Go back to WiFi settings and reconnect to StPeters_Student (or your home WiFi). You simply switch back — nothing is permanently changed.
