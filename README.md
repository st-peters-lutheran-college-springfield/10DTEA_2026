## What this repository contains

Curriculum resources for the Year 10 Digital Technologies unit built around a Raspberry Pi Pico W environmental monitoring system for community Yarning Circles. All resources are published via GitHub Pages and linked into Microsoft Teams and OneNote ClassNotebook.

| File | Purpose | Audience |
|------|---------|----------|
| `Year10_DT_Lessons_YarningCircle.html` | 4 × 60-minute lesson plans with timing, activities, and differentiation | Teacher |
| `Year10_DT_Teacher_Modelling_Guide.html` | I Do / We Do / You Do frameworks, video library, discussion prompts | Teacher / Cover teacher |
| `Year10_DT_Student_Worksheets.html` | Interactive worksheets for Lessons 1–4 + folio checklist | Students |
| `pico_web_extension_guide.html` | Step-by-step coding guide for extending the Pico W web server | Students |
| `pico_dht22_led_server.py` | Base MicroPython code — DHT22 sensor + LED + web server | Students |

---

## Hardware required (per student pair)

- Raspberry Pi Pico W
- DHT22 temperature and humidity sensor → GP13
- Red LED + 220Ω resistor → GP11
- Breadboard + jumper wires
- USB cable (data-capable)
- Computer with [Thonny IDE](https://thonny.org/) installed

Optional extensions (from kit):
- Active buzzer → GP15
- Tactile push button + 10kΩ resistor → GP14
- Green, yellow, red LEDs → GP10, GP11, GP12
